# OmniML

**Autonomous HITL Machine Learning Pipeline**

Powered by `Groq gpt-oss-120b` · `LangGraph` · `Kaggle` · `ArXiv`

---

### How it works

Describe your ML problem in plain English.
OmniML handles everything else autonomously.

| Stage | What happens |
|-------|-------------|
| Architecture | Groq designs your neural network |
| Visual Editor | You refine it in the flow canvas |
| Dataset | Real data sourced from Kaggle & HuggingFace |
| EDA | Live profiling — distributions, correlations, outliers |
| Training Config | Set epochs, optimizer, regularization |
| HPT | Optuna finds optimal hyperparameters |
| Training | Live loss/accuracy charts |
| ArXiv | Your results vs state-of-the-art research |
| Report | Professional PDF export |
