# 🤖 OmniML — Autonomous HITL Auto-ML Pipeline

> **Powered by Groq `openai/gpt-oss-120b` · LangGraph · Kaggle · PyTorch · Scikit-Learn**

---

## How It Works

| Step | Agent | Action |
|------|-------|--------|
| 1 | 🧠 AI Architect | Analyses your query, picks the 3 optimal architectures, and explains them simply |
| 2 | 🤚 You (HITL) | Choose the model architecture that fits your expertise |
| 3 | 🔍 Kaggle Sourcer | Searches Kaggle for the 3 best **real** datasets based on your chosen model |
| 4 | 🤚 You (HITL) | Pick your dataset |
| 5 | ⚙️ Engineer Agent | Writes a complete, runnable PyTorch or Scikit-Learn training script |
| 6 | 🚀 Execution Sandbox | Runs the script, enforces data safety caps, and captures training metrics |
| 7 | 📊 Evaluator Agent | Produces a professional Technical Report (PDF) and JSON metrics |
